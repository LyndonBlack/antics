# Security and takedown contact

`antics` reads a handful of local game files and a few command-line options; it does not open
network connections. If you find a security problem (for example a crash or memory error triggered by
a crafted data file), please report it privately through GitHub's
**Security → Report a vulnerability** form on this repository rather than in a public issue.

If you hold rights in *Spy vs. Spy III: Arctic Antics* or the *Spy vs. Spy* property and have a
concern about this project, contact the author through the same route; see `docs/NOTICE.md`.
